## 登录与访问问题

### 忘记密码

在登录页选择**忘记密码？**并输入你的邮箱。你会收到一个重置链接——设置新密码后即可登录。

### 使用 Google 或 GitHub 登录

如果你的工作区启用了单点登录，请在登录页使用 **使用 Google／GitHub 继续**。用你在别处使用的同一个邮箱登录，AgentBook 会自动把它关联到你的账户。

### 提示"会话已过期"或被弹回登录页

会话可以维持一段时间，但确实会过期。重新登录即可——你的数据不受影响。如果刚登录就反复出现，请清除该站点的 Cookie 后重试。

### 没有收到验证邮件或重置邮件

先检查垃圾邮件。邮件能否送达取决于你工作区的邮件配置——如果尚未配置经过验证的发件域名，部分邮件可能收不到。请咨询你的管理员，或先用单点登录进入。

### 账户被停用

如果你看到账户被停用的提示，说明管理员暂停了访问权限。请联系他们重新启用。

仍然进不去？请联系你的工作区管理员——他们可以在 **管理 → 用户** 中重置访问权限、重新启用账户或调整角色。
