AgentBook 在 iPhone 和 Android 上都可以作为应用安装——无需应用商店，也不用下载。它会全屏打开，拥有自己的主屏幕图标，并且可以推送发票提醒、报税截止日期之类的通知。

Android 会显示原生的安装提示，点一下即可。iOS 不允许任何网站主动弹出该提示——苹果要求你在 Safari 的"分享"菜单里手动操作几步。下面是两个平台的完整说明。

## iOS（iPhone 或 iPad）

必须使用 **Safari**——Chrome、Firefox 等 iOS 浏览器无法安装主屏幕应用，因为它们不被允许为此调用 Safari 的底层引擎。

### 第 1 步 — 点击"分享"图标

在 Safari 中打开 [agentbook.brainliber.com](https://agentbook.brainliber.com)，然后点击工具栏中的**分享**图标（一个带向上箭头的方框）。在 iPhone 上通常位于屏幕底部，在 iPad 上位于右上角。

![Safari 工具栏中高亮显示的分享图标](/docs/install-app/ios-step-1-share.svg)

### 第 2 步 — 找到"添加到主屏幕"

分享面板会打开，顶部是一排快捷分享目标，下方是操作列表。向下滚动，直到看到**添加到主屏幕**，然后点击它。

![iOS 分享面板中高亮显示的"添加到主屏幕"](/docs/install-app/ios-step-2-add-to-home-screen.svg)

> **没看到这一项？** 点击列表底部的**编辑操作**，然后打开"添加到主屏幕"——某些 iOS 版本会默认隐藏不常用的操作。

### 第 3 步 — 确认名称并点击"添加"

iOS 会显示一个预览，包含 AgentBook 图标和一个可编辑的名称（除非你想改，否则保留"AgentBook"即可）。点击右上角的**添加**。

!["添加到主屏幕"确认对话框，"添加"按钮高亮显示](/docs/install-app/ios-step-3-confirm.svg)

完成了——AgentBook 图标现在像其他应用一样出现在你的主屏幕上。打开它会全屏启动，没有 Safari 地址栏。

> **提示：** 首次打开已安装的应用时，如果你希望接收发票和报税截止日期提醒，iOS 会询问通知权限。之后随时可以在 iOS 设置 → AgentBook → 通知 中更改。

## Android

任何基于 Chromium 的浏览器（Chrome、Edge、Brave、三星浏览器）都可以一键安装 AgentBook，无需手动操作。

打开 [agentbook.brainliber.com](https://agentbook.brainliber.com)，在地址栏中找到**安装图标**（一个带向下箭头的小显示器）。点击它，然后在确认提示中点击**安装**。

![Chrome 地址栏中高亮显示的安装图标](/docs/install-app/android-install.svg)

如果看不到该图标，请打开浏览器的 **⋮ 菜单**，选择**安装应用**（或**添加到主屏幕**）——效果相同。

## 已经安装了？

如果 AgentBook 已在你的主屏幕上，请从那里打开（而不是从浏览器书签），这样才能获得全屏体验和推送通知。在普通浏览器标签页中打开同一网址仍然可用，但会运行在浏览器界面内。
