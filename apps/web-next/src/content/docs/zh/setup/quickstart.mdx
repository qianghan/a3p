## 五分钟快速上手

AgentBook 是你的 AI 记账助理，同时管理**企业**和**个人**财务。你不需要任何会计知识——助理会自动分类、对账，并回答你的问题。

### 1. 创建账户

用邮箱注册（也可以使用 Google 或 GitHub 登录）。企业账目和个人账目会保存在同一个地方，随时都能看到完整的财务全貌。

### 2. 填写业务信息

首次登录时，你需要设置**业务类型**、**国家/地区**、**币种**，以及**会计基础**（收付实现制或权责发生制）。这些设置会影响税务估算和报表。之后可以随时在 **配置 → 业务资料** 中修改。

### 3. 连接银行账户

通过我们的银行连接功能安全地关联账户。交易会自动导入，助理随即开始分类。想先手动开始？你也可以手工录入第一笔支出，或者直接拍一张收据。

### 4. 认识你的助理

打开聊天窗口，试着输入：

- *"记录 5 元咖啡"*
- *"这个月的支出汇总"*
- *"我应该预留多少税款？"*

助理会边记录、边解释、边归档——在网页端和 Telegram 上都可以。
