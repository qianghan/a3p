## 记录第一笔支出

把一笔支出录入 AgentBook 有三种方式，用当下最顺手的那种就好。

### 拍一张收据

在**拍摄**页面（或手机应用）中给收据拍照。助理会通过 OCR 识别商家、金额、日期和税额，推荐一个分类，然后请你确认。照片太模糊？它会告诉你哪些内容没能识别出来。

### 直接告诉助理

在聊天窗口或 Telegram 里，把发生的事说出来就行：

> 记录 42 元与客户的午餐

助理会创建这笔支出、选好分类并确认。发现不对可以顺口纠正——*"不对，这是差旅"*——它下次就记住了。

### 导入表格

有历史数据存在 CSV 里？进入 **支出 → 导入** 上传即可。AgentBook 会映射各列（日期、金额、描述、商家）并自动为每一行分类。在最终确认之前，你可以先逐条核对。

### 复核与修正

凡是助理不确定的内容都会进入你的**待复核队列**——不会有任何静默的猜测。你只要修改过一次分类，助理就会记住你对该商家的偏好。
