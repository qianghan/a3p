## 把 Claude 连接到你的账目

如果你已经在用 Claude，就可以直接在里面访问你的 AgentBook 数据——提问、记录支出、开发票——和在 AgentBook 网站上与助理聊天完全一样。

### 设置方法（大约一分钟）

1. 在 Claude 中打开 **设置 → 连接器（Connectors）**。
2. 点击 **+ 添加自定义连接器**。
3. 粘贴这个地址：`https://agentbook.brainliber.com/api/v1/mcp`
4. 点击**添加**。Claude 会打开一个浏览器标签页，请你用 AgentBook 账户登录。
5. 你会看到一个提示：**"Claude 想要访问你的 AgentBook 数据——是否允许？"** 点击**允许**。
6. 完成——回到 Claude 就可以开始对话了。

这个设置只需做一次。在你主动断开之前，Claude 会一直记住这个连接。

### 试试看

连接之后，可以直接这样问 Claude：

- *"我这个月的支出汇总是多少？"*
- *"记录 50 元与客户喝咖啡的支出"*
- *"给 Acme Inc 开一张 2,000 元的发票"*
- *"这个季度我应该预留多少税款？"*

Claude 会判断你想执行哪个 AgentBook 操作，然后完成剩下的事。

### 主动权始终在你手上

**在保存任何内容之前，Claude 都会停下来请你确认。** 如果你让它记录一笔支出或发送一张发票，它会先明确展示将要执行的操作，然后等你点头。没有这个明确的批准，就不会有任何内容写入你的账目——你随时可以拒绝。

单纯的查询（"我上周花了多少钱？"）不需要确认——只有会改动账目的操作才需要。

### 随时断开连接

在 AgentBook 中进入 **设置 → 已连接应用**，点击 Claude 旁边的**撤销**。访问权限会立即中断。
