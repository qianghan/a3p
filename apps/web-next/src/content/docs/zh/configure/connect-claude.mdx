## 通过 MCP 连接 Claude

AgentBook 可以作为 **Model Context Protocol（MCP）服务器**运行，因此你可以直接在 Claude 或任何兼容 MCP 的客户端中访问账目、管理财务。在一个地方就能和你的记账助理对话。

### 你可以做什么

连接之后，Claude 可以：

- **查询账目** — "我这个月的支出汇总是多少？""我应该预留多少税款？"
- **记录交易** — "记录 50 元咖啡""给 Acme Inc 开一张 2,000 元的发票"
- **分析财务** — "给我看看各商家的支出明细""我的现金流情况如何？"
- **草拟方案** — "如果我买一台 3,000 元的笔记本会怎样？""这个季度我能花多少？"

### 把 AgentBook 添加到 Claude

#### 方式一：Claude Desktop

1. 打开 **Claude Desktop 设置**（左下角的齿轮图标）
2. 进入 **连接器（Connectors）**
3. 点击 **+ 添加自定义连接器**
4. 粘贴这个网址：`https://agentbook.brainliber.com/api/v1/mcp`
5. 点击**添加**
6. 页面会跳转，请用你的 AgentBook 账户登录
7. 授予 Claude 访问账目的权限
8. 完成——Claude 现在可以访问你的 AgentBook 数据了

#### 方式二：Claude API／网页版

1. 打开 [claude.ai](https://claude.ai) 并进入**设置**
2. 找到 **连接器（Connectors）**
3. 点击 **+ 添加自定义连接器**
4. 粘贴这个网址：`https://agentbook.brainliber.com/api/v1/mcp`
5. 按提示完成登录与授权
6. 开始对话——在相关场景下 Claude 会主动建议 AgentBook 操作

### 重要：保存前需要确认

**写入类操作始终需要你在 Claude 中批准。** 在助理记录支出、创建发票或改动账目之前，Claude 会明确展示接下来要做的事，并请你确认。这是刻意设计的安全机制——没有你明确的"同意"，任何内容都不会被保存。

这意味着：

- 每一笔交易都由你掌控
- 错误在进入账目之前就能被拦下
- 你可以在确认前先复核并修改这些提议

### 疑难解答

**我在连接器里看不到 AgentBook**

请确认 MCP 服务器正在运行，并且你的 AgentBook 账户处于激活状态。你可能需要刷新 Claude 或重新加载浏览器。

**Claude 说它无法访问我的数据**

请检查你是否在登录流程中授予了 Claude 权限。前往你的 [AgentBook 账户设置](/docs/zh/configure/business-profile)，确认该连接仍然有效。

**我想撤销访问权限**

你可以在 **设置 → 已连接应用** 中断开 Claude 与 AgentBook 账户的连接。撤销之后，Claude 将不再能访问你的账目。
