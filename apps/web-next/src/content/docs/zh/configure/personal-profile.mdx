## 个人资料

**业务资料**告诉 AgentBook 该如何为你的交易做账。**个人资料**则告诉助理*你*是谁——这样它关于税务和个人理财的回答才真正针对你的处境，而不是一条通用的经验法则。

### 为什么值得填

如果没有资料就去问税务或理财问题，助理只能泛泛而谈，或者每次都要你把情况重述一遍。资料完整之后，它已经知道你的申报身份、受抚养人、雇佣类型和大致收入——因此可以立刻给出具体、有用的回答，而且它会把这些背景带进每一次对话，而不只是提到"税"的那几次。

![对比图：没有资料时的泛泛回答，与资料完整后个性化、结合背景的回答](/docs/personal-profile/before-after-chat-context.svg)

### 它不会索取什么

个人资料从不索取政府税号（SSN、SIN 等）。会计师用得上的其他信息——姓名、出生日期、地址、婚姻状况、受抚养人、雇佣类型、职业，以及大致的收入估计——都会问，但不会问这么敏感的东西。

### 完善你的资料

1. 如果还没填完，你会在仪表盘上看到一行提醒横幅。它随时可以关闭——之后从设置里补填同样有效。

   ![仪表盘横幅，提示用户完善个人资料以获得更好的税务和财务建议](/docs/personal-profile/dashboard-reminder-banner.svg)

2. 打开 **设置 → 个人资料**（或点击横幅上的**完善资料**）。填写你愿意分享的内容——每一项都是可选的，不过填得越多，助理的建议就越具体。

   ![设置页个人资料选项卡，显示姓名、出生日期、地址、婚姻状况、受抚养人、雇佣情况和预计收入等字段，以及保存按钮](/docs/personal-profile/settings-personal-profile-form.svg)

3. 点击**保存资料**。你随时可以回来更新——生活会变，助理对你的了解也应该跟着变。

### 也把往年的报税表传上来

顺手一提，同一个选项卡里还有**上传往年报税表**的选项。上传最近 1–2 年的申报表（PDF），能让助理有真实的历史依据可用——每当你在聊天里问税务问题时，它本来就会去查这份文件。这是可选的，但两者结合起来——资料加往年申报表——才能把"这是一条通用规则"变成"结合你过去两年和当前状况，你该这么做"。
