## 支持的国家和地区

AgentBook 目前在**美国**、**加拿大**和**澳大利亚**提供完整支持。你的国家只需在**业务资料**中设置一次，它会决定下游的一切——税表、里程费率、薪资预扣、销售税和币种。

更多国家正在路上。如果还没有你所在的国家，AgentBook 的记账与开票部分（记录支出、发送发票、生成报表）在任何地方都一样可用——只有下面这些与税务直接相关的部分目前仅限美国／加拿大／澳大利亚。

### "支持"具体指什么

| | 🇺🇸 美国 | 🇨🇦 加拿大 | 🇦🇺 澳大利亚 |
|---|---|---|---|
| 所得税估算 | 联邦税级（单身与夫妻联合申报） | 联邦 + 全部 13 个省和地区 | ATO 个人税级，Pty Ltd 则用统一公司税率 |
| 自雇税 | 社会保障税 + 医疗保险税 | CPP，全国统一（魁北克见下方说明） | 医保税（Medicare Levy） |
| 销售税 | 各州税率 | 按省份的 GST/HST/PST | GST |
| 里程 | IRS 标准费率（统一，按英里） | CRA 两档费率（按公里，年内超过 5,000 公里后降档） | ATO 每公里计价法（统一，按公里） |
| 薪资 | 联邦 + 各州预扣、940/941 表、W-2 | 联邦 + 省级预扣、T4/T4A、魁北克独立的 QPP/QPIP/QC-EI | PAYG 预扣、养老金保障金——单点薪资申报见下方说明 |
| 银行同步 | 支持（Plaid） | 支持（Plaid） | 支持（Basiq） |
| 税务资料包（年终导出） | Schedule C 格式 | T2125 格式 | ITR（个人所得税申报表）格式 |
| 币种 | USD | CAD | AUD |

以下是几点如实的说明，以免这里有任何过度承诺：

- **澳大利亚的银行同步使用与美国／加拿大不同的服务商。** 由于 Plaid 不支持澳大利亚的银行，澳大利亚租户改为通过 Basiq 连接，这是一家获得 CDR 认证的澳大利亚数据服务商——连接流程、自动匹配和每日同步的工作方式与美国／加拿大的 Plaid 完全一致。
- **这里的澳大利亚薪资功能不会向 ATO 报送单点薪资申报（STP）。** 它会为你自己的记录正确计算 PAYG 预扣和养老金保障金，但按法律要求把每次发薪报送给 ATO，你仍然需要支持 STP 的软件（或你的 BAS／税务代理）。
- **魁北克的 QPP 和 QPIP 在薪资中已被正确建模**（针对员工，使用真实的 CRA T4 方框编号），**但自雇税估算**（针对自雇人士）**目前仍套用加拿大其他地区通用的 CPP 算法**——尚未为自雇申报人的估算替换成魁北克更高的 QPP 费率，也尚未加入 QPIP。
- **澳大利亚的 GST 默认按标准 10% 税率应用到每张发票**——你可以逐张发票覆盖该税率（例如在尚未需要注册时改为 0%）。AgentBook 不会自动检测你的营业额何时越过 ATO 规定的 75,000 澳元强制注册门槛并替你切换；快速报税流程中会就此提问，好让你心里有数。
- **每日津贴（固定的每日餐饮及杂费标准）仅限美国**——它基于美国 GSA 的费率表，加拿大和澳大利亚目前还没有对应的数据。请改为记录实际的里程和餐饮支出。

### 这些设置会体现在哪里

- **业务资料**（`/settings`）是你设置国家、地区／州／省和币种的唯一入口——见[设置业务资料](/docs/zh/configure/business-profile)。
- **报表与税务**中的数字（所得税、自雇税、季度预缴）会自动采用你所在国家的真实规则——见[报表与税务](/docs/zh/working/reports-and-tax)。
- **快速报税**和 **Student Success** 在这三个国家都可用，并配有各国专属的问题——见[快速报税](/docs/zh/working/tax-fast-track)和 [AgentBook 学生版](/docs/zh/setup/for-students)。
