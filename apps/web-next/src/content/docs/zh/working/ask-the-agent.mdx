## 向助理提问

使用 AgentBook 最快的方式就是和助理对话。在网页端或 Telegram 上都可以——是同一个助理，看到的是同一份财务数据。

### 可以问些什么

- **记录** — *"记录 5 元咖啡"*、*"给 Beta Co 开一张 1,500 元的发票"*
- **查询** — *"这个月的支出汇总"*、*"这个季度我在软件上花了多少钱？"*
- **规划** — *"我应该预留多少税款？"*、*"如果我买一台 3,000 元的笔记本会怎样？"*
- **更快报税** — *"开始我的快速报税流程"* 会带你梳理今年与去年相比有哪些变化，然后起草一份估算和一封给会计师的说明信——见[快速报税](/docs/zh/working/tax-fast-track)
- **学生专属搜索** — *"帮我找奖学金"*、*"在奥斯汀附近找带薪实习"*、*"帮我找室友"*——如果你订阅了 Student Success，见 [AgentBook 学生版](/docs/zh/setup/for-students)
- **个人 + 企业** — *"这个月我能负担一笔 2,000 元的采购吗？"* 会同时参考你财务的两侧

### 它是怎么工作的

对于简单的请求，它会立即执行。对于多步骤的请求，它会先拟一份简短的方案给你看，等你点击**继续**后再执行——所以你永远不会被打个措手不及。任何会改动账目的操作，它都会先确认。

### 它会学习

只要纠正一次——*"不对，这家商户属于餐饮"*——它就记住了。久而久之，它会像你一样为常用商家分类；而如果某个建议不再准确，它对该建议的置信度会衰减，于是它会重新询问，而不是一路偏下去。

### 统一视图

因为个人账目和企业账目放在一起，助理能回答纯企业工具答不了的问题——在负担能力、业主提款和税务问题上，把两侧的情况合起来看。
