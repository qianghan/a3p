## 支出与收据

### 录入方式

- **拍照** — 在"拍摄"页面或手机上给收据拍照；OCR 会识别商家、金额、日期和税额。
- **聊天** — 一句*"记录 80 元加油"*就能立刻创建。
- **银行** — 已关联的交易会自动导入并自动分类。

### 分类（以及更正）

每一笔支出都会有一个分类。助理有把握时会自动套用；没把握时，这一条会留在你的**待复核队列**里。

要更正分类，直接告诉助理就行——*"那笔亚马逊的消费属于办公用品"*——或者在列表里编辑。AgentBook 会记住"商家 → 分类"这条规则并在下次套用，于是一次次更正会累积成准确度。

### 拆分与标记

- 把一笔消费**拆分**到多个分类（例如一次仓储超市采购，一部分是耗材，一部分是食品杂货）。
- **企业／个人**标记让混用的账户在税务上保持清晰。
- **周期性**支出可以被跟踪，于是它们是预期之中的，而不是意外。

### 找回被漏掉的钱

问一句*"我有没有漏掉的抵扣？"*，助理会扫描那些你很可能有可抵扣支出却没有记录的分类——这往往就是"匆忙报税"和"真金白银省下来"之间的差别。
